Quantum probability

The M&M Quantum Decay Game

This hands-on analogy introduces quantum probability and half-life using the printed “m” on each candy.

  1. Shake: Place the M&Ms in a cup and shake it. This represents a hidden quantum state before measurement.
  2. Measure: Pour out the candies and observe which side faces up.
  3. Decay: Candies landing “m” side up have “decayed” and can be eaten as a reward.
  4. Repeat: Return the blank-side-up candies to the cup and shake again. Roughly half disappear in each round.

Each candy’s result is random, but the behavior of the whole group becomes predictable, just as many random decay events produce a measurable half-life.
